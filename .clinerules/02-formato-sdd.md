# Formato de Output SDD

## Regla Principal
Responde ÚNICAMENTE con diffs unificados (formato diff -u)
aplicables con `patch -p1`. Sin explicaciones fuera del diff.

## Excepción de Comandos
Si la tarea requiere solo un comando de terminal, responde
con un único bloque ```bash de una sola línea verificada.

## Prohibición
No incluyas bloques de código sin formato diff.
No incluyas prosa explicativa fuera de los comentarios del diff.
